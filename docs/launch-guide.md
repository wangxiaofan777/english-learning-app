# TalkBuddy 上线手册（部署 / 小程序 / App）

> 面向首次上线的逐步操作手册。已确认的决策：
> **主体 = 个体工商户**；**云 = 阿里云轻量应用服务器**（LLM 已在阿里云百炼，同生态最顺）；
> **上线路径**：H5（最快，备案后即可）→ 微信小程序（需深度合成类目）→ iOS/Android App（软著 + App 备案）。
>
> **关键认知：上线的瓶颈不是技术，是资质审核的等待时间**（备案 1-3 周、软著 1-2 月、App 备案 3-22 工作日）。
> 下面的长周期事项**第一周就要全部提交**，等待期间并行做技术部署。
>
> 政策类细节（价格、周期、入口名称）以官方当期页面为准，本文写的是 2026 年的主流路径与常见驳回原因。

---

## 一、云选型：为什么是阿里云轻量应用服务器

| 维度 | 阿里云 ✅ 已定 | 腾讯云 | 海外服务器 |
| --- | --- | --- | --- |
| LLM 同生态 | **已是百炼 DashScope 客户**：同账号、统一账单、内网低延迟；申请「大模型已备案合作协议」材料最顺 | 需跨云调阿里云接口，材料要走两个主体 | 同左，且跨境延迟高 |
| 备案 | 备案服务码体系成熟，初审 1-2 天 | 同样成熟 | **不备案 = 微信 request 合法域名无法配置，小程序直接不可用** |
| 轻量 2C4G 价格 | 活动价约 199~379 元/年 | 约 315~541 元/年 | ≈5-10 倍 |
| 部署模型 | Docker Compose 单机，与现有 `docker-compose.yml` 完全一致 | 同左 | 同左 |

**不推荐的替代方案**：Serverless 容器（SAE / CloudBase Run）——本项目有 SSE 长连接 + 常驻线程池，按量计费反而更贵；海外服务器——小程序合法域名强制已备案域名，走不通；云数据库 RDS——初期自托管 PG + 每日备份足够，日活过千再迁。

**购买规格**（阿里云控制台 → 轻量应用服务器）：
- 地域：就近选（华东-杭州 / 华东-上海 / 华南-深圳均可，备案省份与服务器所在省份可以不同）
- 镜像：Ubuntu 24.04（或 22.04）
- 套餐：2核4G（50GB ESSD 含），时长 1 年（新购活动价最划算，**买 ≥3 个月才能申请备案服务码**）
- 安全组/防火墙：只放行 22（SSH，建议限自己的 IP）、80、443
- 购买后：控制台开启「自动快照」策略（磁盘级兜底备份，一天一档保留 7 天）

## 三、阶段流程（逐步操作）

### Phase 0 · 第 0 周：资质全启动

#### 3.0.1 个体工商户注册（已定路径）

**在哪办**：本省政务服务网 / 一网通办平台线上办（浙江「浙里办」、广东「粤商通」、上海「一网通办」、江苏「苏服办」等），或线下到经营场所所在区的市场监督管理局窗口。线上 1-3 个工作日发证，全程免费。

**四项填写（关键，决定后续备案顺不顺）**：

| 项目 | 怎么填 | 为什么 |
| --- | --- | --- |
| 名称 | 行政区划 + 字号 + 行业 + 组织形式，如 `杭州市西湖区英搭信息技术工作室`。字号 2-4 个字，提前想 3 个备选（重名要换） | 名称规范硬性要求 |
| 经营场所 | 自有/租赁住宅可走「住所承诺制」；没有合适场所用园区**集群注册/托管地址**（免费到几百元/年，电商园、创业园都提供） | 与你实际居住地分离也可 |
| 经营范围 | 勾选/填写：`软件开发；技术服务、技术开发、技术咨询；信息系统集成服务；信息技术咨询服务；人工智能应用软件开发；互联网数据服务`。**绝对不要出现「教育培训」「教育咨询」字样** | 经营范围含"教育"会在 ICP 备案/小程序类目审核时触发前置审批要求，个人办不了办学许可证，等于卡死 |
| 经营者 | 你本人身份证 | — |

**发证后 3 件事**：
1. 下载/领取**电子营业执照**（微信小程序「电子营业执照」可下载，后续各类注册直接用）；
2. **税务登记**：电子税务局线上办，默认小规模纳税人；季度开票 ≤30 万免增值税（现行政策），没收入就零申报（每月一次线上点报，或装「个人所得税」/电子税务局 APP 操作）；个体户经营者按「经营所得」年度汇算，利润低时税负很低；
3. 刻章/对公账户：**非必需**。微信认证走「经营者人脸验证」不需要对公户；想开也可以（银行免费-几百元），备用。

#### 3.0.2 域名购买与实名（当天完成）

- 阿里云控制台 → 域名注册：买 `talkbuddy.cn` / `talkbuddy.com` / `yingyudazi.cn` 之类，`.cn`/`.com` 均可（**必须是国内可备案后缀**，不要买 .io/.app 等不可备案后缀）；
- 实名认证：**用个体工商户主体**（填统一社会信用代码 + 上传执照），不要用个人实名——备案主体、小程序主体、域名实名三者一致最省事；
- 实名通过后域名才能用于备案（当天-1 天）。

#### 3.0.3 软著申请（第 0 周提交，安卓上架的瓶颈）

**办理入口**：中国版权保护中心（ccopyright.com.cn）→ 计算机软件著作权登记申请，全程线上，官费 0。

**著作权人怎么写**：直接写**个体工商户字号全称**（与执照一致），不要写个人——后续 App 备案主体是个体户，版权人主体一致避免商店审核扯皮。

**软件名称**：规范格式为「字号 + 用途 + 软件/V1.0」，如 `英语搭子英语口语练习软件 V1.0`。**名称主体词必须与 App 备案名/上架名一致**（都含「英语搭子」），安卓商店执行"软著名 = APP 备案名 = 应用名"三一致原则。

**材料清单（都能从现有工程生成）**：
1. 申请表（在线填写，程序开发日期、发表日期如实填）；
2. **源程序**：前、后各连续 30 页，共 60 页（整段代码不足 60 页则全交），每页 ≥50 行（末页可不足），页眉标注软件名+版本号+页码。直接导出后端 Java 关键源码 + 前端 TS/Vue 源码拼 PDF；
3. **文档一份**：用户手册 / 操作说明书 / 设计说明书任选其一，同样按前后 30 页规则。建议用产品文档（docs/product-design.md 改写成用户手册更省事）+ 截图；
4. 个体工商户营业执照复印件（盖章/签字）。

**周期**：普通登记 1-2 个月（官网称缩短到数周，以受理回执为准）；急用安卓上架走加急代理 10-15 工作日（约 500-800 元）。**华为商店接受「APP 电子版权认证证书」替代软著**（电子版权联合服务平台，出证更快），可作过渡。

#### 3.0.4 Apple Developer（iOS 上架）

- 入口 developer.apple.com → Enroll。两种类型：
  - **个人账号（推荐起步）**：$99/年，身份证+人脸即办，1-2 天通过。App Store 开发者显示个人姓名拼音——对工具类应用无影响；
  - 组织账号（用个体户执照）：需要先申请 **D-U-N-S 邓白氏编码**（免费，5-10 工作日），账号显示个体户名称。不着急的话可以直接申请这个，更正式；两者后续可迁移。
- 注意：iOS 上架中国区要填 **App 备案号**（§3.4.2），个人账号 + 个体户主体的 App 备案可以正常搭配（备案校验的是 App 名称与备案名一致，不是开发者账号主体）。

#### 3.0.5 微信小程序注册 + 认证（当天可完成）

1. mp.weixin.qq.com → 立即注册 → 小程序 → 主体选**个体工商户**；
2. 材料：电子营业执照、经营者身份证、一个未绑定过公众平台的邮箱、管理员本人微信；
3. **微信认证**（300 元/年）：个体户走「经营者人脸验证」通道，无需对公账户；认证后才能申请深度合成等资质类目；
4. 小程序名称：`英语搭子`（可能被占用，备选 `英语搭子AI` / `TalkBuddy 英语搭子`）；名称、头像、简介**不得出现"培训/课程/授课"**（§四）；
5. 顺手配置： members 开发者/体验者微信号、隐私保护指引先占位（§3.3 第 2 步细化）。

#### 3.0.6 ICP 备案（最长的等待，第 0 周提交）

**前提**：域名已个体户实名 + 已有阿里云服务器（≥3 个月订单）。阿里云控制台 → ICP 备案 → 申请**备案服务码**（轻量服务器每台可提供若干个）。

**逐步**（阿里云备案控制台，全程 App 拍材料 + 人脸核验）：
1. **主体信息**：填个体工商户，统一社会信用代码、经营者身份证；网站负责人 = 经营者本人；
2. **网站信息**：
   - 域名：你买的域名；
   - **网站名称**：填「英语搭子」或「TalkBuddy」——**不要带"教育/培训/课堂/学院"等词**，带词会要求教育前置审批直接退回；
   - 服务内容/类型：选「其他」或「博客/个人空间」类目（避免触发前置审批的选项），网站内容如实描述为「英语口语练习工具，提供 AI 对话练习」；
3. 上传材料：执照原件照片、身份证正反面、人脸核验；
4. 阿里云初审 1-2 个工作日（驳回会短信+邮件说明原因，改了重提）；
5. 工信部短信核验（初审通过后几分钟收到，24 小时内点链接完成）；
6. 管局审核 **1-20 个工作日**（各省不同，无法加急）→ 通过后获得备案号，如 `浙ICP备2026XXXXXX号`。

**通过后立即做**：H5 页面底部挂备案号并链接 beian.miit.gov.cn；30 天内如果变更信息要同步更新备案。

**常见驳回原因**：网站名称含敏感词/教育词；经营范围含"教育"；执照照片模糊；场所信息与备案填写不一致；服务内容选了需要前置审批的类型。

### Phase 1 · 第 1 周：服务器上线（技术活，1-2 天）

```bash
# 1. 阿里云控制台：轻量应用服务器 2C4G，系统镜像 Ubuntu 24.04
#    防火墙只放行 22/80/443；开启自动快照

# 2. 服务器初始化
ssh root@<IP>
curl -fsSL https://get.docker.com | bash        # Docker + compose 插件

# 3. 部署代码
git clone <你的仓库> /opt/talkbuddy && cd /opt/talkbuddy
cp .env.example .env && vim .env                # 填全部[必填]项（密钥全部重新生成，勿复用本地值）
./scripts/gen_certs.sh                          # 先用自签名，备案+解析后换 CA 证书
docker compose up -d --build

# 4. 域名解析：控制台 → 云解析 DNS → A 记录 @ 和 www → 服务器 IP
# 5. ICP 备案通过后：申请免费 CA 证书（控制台「数字证书管理服务」每年 20 张免费 DV 证书）
#    下载 nginx 格式，替换 certs/fullchain.pem + privkey.pem，docker compose restart web
# 6. 把 compose 里 "8443:443" 改为 "443:443"（备案后正式启用）
```

验收：`https://你的域名/api/v1/health` 返回 `{"code":0,...}`；`http://` 自动跳 `https://`。

**部署当天顺手做**：
- crontab 每日数据库备份 + 传 OSS（README checklist 有命令）：`0 3 * * * cd /opt/talkbuddy && docker compose exec -T postgres pg_dump -U lingo lingo | gzip > /opt/backup/lingo_$(date +\%F).sql.gz && find /opt/backup -mtime +14 -delete`
- 阿里云云监控 → 站点拨测：监控 `https://域名/api/v1/health`，异常短信/钉钉告警；
- 百炼控制台：设置月度 token 消费预警（建议先设 50 元档观察一周）。

### Phase 2 · 第 2-3 周：H5 上线（备案通过后立即可用）

- ICP 备案通过 → 域名可直接访问 → **H5 是第一个上线渠道**，可以先获客/验证；
- 页面底部挂 ICP 备案号（合规硬性要求）；
- 服务器上跑一遍冒烟：`ADMIN_TOKEN=xxx bash scripts/smoke.sh`，17 项全 PASS 才算部署成功。

### Phase 3 · 第 3-5 周：微信小程序上线（合规最重的一端）

**1. 代码配置**
- `app/src/manifest.json` 填入真实 appid（替换 `touristappid`）；
- `app/.env.production` 填 `VITE_API_BASE_URL=https://你的域名`；
- `npm run build:mp-weixin` → 微信开发者工具导入 `app/dist/build/mp-weixin`。

**2. 小程序后台配置**（mp.weixin.qq.com）
- 开发管理 → 开发设置 → **服务器域名**：request 合法域名 + socket 合法域名都填 `https://你的域名`（域名必须已备案，且不带路径）；
- 设置 → **用户隐私保护指引**：逐条声明——`昵称`（登录展示）、`麦克风`（跟读评分与语音识别）、`相册/保存`（成绩海报保存到相册）。**未声明的接口调用会直接审核失败**；
- 服务类目：先加基础类目（如「工具-效率」「工具-信息查询」，无需资质）。

**3. 深度合成-AI 问答类目（AI 对话功能必需）**
- 你们走**第三方已备案大模型路径**（阿里云百炼/通义千问是已备案模型）；
- 向阿里云索取材料：百炼控制台/工单申请「**互联网信息服务算法备案证明 + 合作协议**」（说明用于微信小程序深度合成类目申请）；**协议里的模型名称必须与备案名称完全一致**——最常见的驳回原因；
- 备案证明彩色打印盖章后与协议一起在小程序后台「类目申请」上传；
- 审核通常 3-7 个工作日。

**4. 提审节奏**
- 开发版自测（开发者工具勾选「不校验合法域名」可连 localhost）→ 上传体验版 → 真人全流程测试（登录、测评定级、对话流式、跟读、复习、Boss）→ 提交审核；
- 首次提审预留 1-2 周（常见 1-2 轮驳回）；
- **常见驳回点**：类目与实际功能不符；隐私指引未声明用到的权限；页面出现"课程/培训"表述（§四）；名称/头像含敏感词；有付费引导但未接微信支付。

### Phase 4 · 第 4-8 周：App 上线（iOS 与 Android 并行）

#### 3.4.1 HBuilderX 云打包

**Android**：
1. 自建签名证书（不要用 DCloud 云端证书，私钥不可控）：
   ```bash
   keytool -genkeypair -v -keystore talkbuddy.keystore -alias talkbuddy \
     -keyalg RSA -keysize 2048 -validity 10000
   # 提示输入： keystore 密码、组织单位（填个体户字号）、CN（填个体户字号）
   # ⚠️ keystore 和密码永久保存（丢失=无法更新应用），并备份到密码管理器
   ```
2. HBuilderX → manifest.json → 基础配置：**Android 包名** `cn.talkbuddy.app`（备案前定好，备案后不能改）→ 云打包 → Android（使用自有证书）→ 出 APK；
3. 导出备案要用的信息：`keytool -list -v -keystore talkbuddy.keystore` → 记下 **MD5 指纹**与**公钥**。

**iOS**：
1. Apple Developer 后台：创建 App ID（Bundle ID 填 `cn.talkbuddy.app`，与 Android 包名一致省心）→ 制作 Distribution 证书（.p12）+ 描述文件；
2. HBuilderX 云打包 → iOS → 上传 .p12 + 描述文件 → 出 ipa；
3. 备案要用的信息：`openssl x509 -in 证书.cer -noout -fingerprint -sha1`（指纹）、`openssl x509 -pubkey -noout`（公钥）。

#### 3.4.2 App 备案（拿到备案号才能上商店）

在已通过的 ICP 备案系统里**追加 App 信息**（阿里云备案控制台 → App 备案）：

| 字段 | Android 填什么 | iOS 填什么 |
| --- | --- | --- |
| App 名称 | `英语搭子`（=软著名=上架名） | 同左 |
| 平台 | Android | iOS |
| 包名 / Bundle ID | `cn.talkbuddy.app` | `cn.talkbuddy.app` |
| 公钥 | keystore 的公钥 | 签名证书公钥 |
| 证书指纹 MD5 | keytool 输出的 MD5 | openssl 输出（按平台要求换算） |

提交后：阿里云初审 1-2 天 → 短信核验 → 管局 3-22 工作日 → 拿到**App 备案号**。

#### 3.4.3 iOS（App Store）

1. App Store Connect → 创建 App（名称=`英语搭子`，与备案名一致，后台会自动与工信部校验）→ **App 信息页填中国区 ICP/App 备案号**（强制）；
2. Transporter 上传 ipa → TestFlight 内测（先给几个真人用一周）；
3. 提审前自查：隐私政策 URL（放 H5：`https://域名/privacy.html`，上线前写好）；PrivacyInfo.xcprivacy 隐私清单（uni-app 云打包可在 manifest 配置）；**AI 生成内容需有举报机制**——应用内加「举报」入口（V2 待办，提审前加上）；不接 IAP 就不要出现任何付费引导；
4. 首次审核 1-3 天/轮。

#### 3.4.4 Android（各商店）

第一批：华为 + 小米 + 应用宝（覆盖大半安卓用户），跑通后补 OPPO/vivo。

每家流程一致：注册开发者账号（**选企业类型、用个体户执照**，部分需对公/法人验证或保证金）→ 创建应用 → 上传 APK → 填软著/版权证明 + App 备案号 + 隐私政策 URL + 权限用途说明（麦克风、网络、保存相册逐条写用途）→ 提审 1-3 天。

**共性硬门槛**：软著（或华为电子版权认证）+ App 备案号 + 隐私政策。名称三一致（软著名=备案名=应用名）。

## 四、合规与风险（必读）

### ⚠️ 1. 教育类目红线：英语 = 学科类培训

「双减」后**少儿英语按学科类培训管理**（[教育部：线上学科类培训机构由备案改为审批制](http://www.moe.gov.cn/srcsite/A29/202109/t20210918_564368.html)，需要《民办学校办学许可证》+ 全国校外教育培训监管与服务综合平台备案——个人/小团队办不下来）。本产品含小学/初中/高中派课方向，**不能以「在线教育/培训机构」类目和口径上线**（[微信小程序服务类目及资质要求](https://developers.weixin.qq.com/minigame/product/material/)，教育服务类目明确要求办学许可等资质；英语工具类是否需要资质参考[微信社区官方答复](https://developers.weixin.qq.com/community/develop/doc/0008e4755ccc60a5b374036726fc00)）。

**务实路径：定位为「AI 学习工具」**：
- 类目避开「教育服务-在线教育」，选工具类/教育信息服务（以[提审时类目要求](https://developers.weixin.qq.com/minigame/product/material/)为准）；
- 全端文案**不出现**「培训」「授课」「班课」「名师教学」「课程售卖」等表述——用「AI 陪练」「口语练习工具」「学习搭子」。**注意一致性**：产品内的「课程目录/课时/Boss 课时」等界面文案是内部术语，提审版本建议统一改叫「练习计划/每日练习」（前端一处术语表可全局替换）；
- 不内置付费购课（付费触发更严资质与资金审查）；捐赠式/会员制也先观望；
- 成人方向（职场/出境口语）风险低；**少儿方向是提审敏感点**，V1 建议服务端下架少儿档或文案明确「工具自用，非培训服务」；
- iOS 审核对教育工具类相对宽松，但同样适用上述措辞原则。

### ⚠️ 2. AI 对话 = 深度合成类目（小程序）

- 深度合成类目不开放个人主体——**个体工商户属于非个人主体、可微信认证**，大概率可行；若提审被以主体类型驳回，升级注册有限公司，软著/域名/备案材料全部可沿用；
- 用已备案第三方大模型（百炼/通义）+ 合作协议是标准路径，材料要求见[腾讯云算法备案资质说明](https://docs.cloudbase.net/ai/release/algorithm-filing)（微信通用规则：协议中的模型名称必须与备案名称完全一致）；
- 对话内容安全：当前依赖 DashScope 自带的内容安全护栏，可满足大部分审核；V2 加用户举报入口与关键词日志。

### ⚠️ 3. 名称一致性（防返工）

**软著名 = App 备案名 = iOS/安卓上架名 = 小程序名称**（允许微小后缀差异，主体词一致最稳）。定名后所有材料统一用「英语搭子」，避免中途改名——改一次名，软著/备案跟着折腾一轮。Android 包名 / iOS Bundle ID 在 App 备案前定死（建议 `cn.talkbuddy.app`），备案后不能改。

### ⚠️ 4. 隐私合规（全端）

- 小程序：用户隐私保护指引逐条声明（昵称、**录音**、保存相册）；
- App：隐私政策 URL（放 H5 域名下，如 `/privacy.html`，提审前写好：收集哪些信息、什么用途、如何删除）；`t_user.phone` 若启用，必须明示用途并支持删除；
- iOS：PrivacyInfo.xcprivacy 清单 + App Tracking 透明度（本项目不追踪，填「否」）；
- 各商店权限用途说明逐条写清楚（麦克风=跟读评分与语音识别）。
