# TalkBuddy 上线手册（部署 / 小程序 / App）

> 面向首次上线的完整流程梳理。结论先行：
> **云厂商选阿里云**（LLM 已在阿里云百炼，备案与合作材料同生态拿取最顺）；
> **关键路径不是技术，是资质**——域名备案、小程序主体、软著，合计 3~6 周日历时间，必须第一周就启动；
> **上线路径**：H5（最快，备案后即可）→ 微信小程序（需企业/个体主体 + 深度合成类目）→ iOS/Android App（软著 + App 备案）。

---

## 一、云选型：阿里云 vs 腾讯云 vs 其他

| 维度 | 阿里云 ✅ 推荐 | 腾讯云 | 海外服务器 |
| --- | --- | --- | --- |
| LLM 同生态 | **已是百炼 DashScope 客户**：同账号、统一账单、内网低延迟；申请「大模型已备案合作协议」材料最顺 | 需跨云调阿里云接口，材料要走两个主体 | 同左，且跨境延迟高 |
| 备案 | 备案服务码体系成熟，初审 1-2 天 | 同样成熟 | **不备案 = 微信小程序 request 合法域名无法配置，小程序直接不可用** |
| 轻量 2C4G 价格 | 活动价约 199~379 元/年 | 约 315~541 元/年 | ≈5-10 倍 |
| 微信生态整合 | 无特别优势 | 云开发/云调用有优势，但本项目后端是自托管 Spring Boot，用不上 | — |
| 运维模型 | Docker Compose 单机，与现有 `docker-compose.yml` 完全一致 | 同左 | 同左 |

**结论：阿里云轻量应用服务器 2核4G（杭州/上海/深圳任一）**。理由：
1. 你们唯一的外部付费依赖就是阿里云百炼的 LLM，把它放同一朵云、同一个账号下，备案材料、发票、故障排查都在一处；
2. 腾讯云对微信的整合优势（云开发、云调用）本项目用不到——后端是自己部署的 Spring Boot，不是微信云开发；
3. 单机 Docker Compose 的部署方式已经过冒烟验证（17/17），2C4G 跑 Postgres + Spring Boot + Nginx 绰绰有余，日活几千内不用升级。

**不推荐的替代方案**（想清楚为什么）：
- **Serverless 容器（阿里云 SAE / 腾讯云 CloudBase Run）**：本项目有 SSE 长连接 + 常驻线程池，按量计费反而更贵，且要改部署方式，V1 不折腾；
- **海外服务器（免备案）**：微信小程序的 request 合法域名**强制要求已备案域名**，海外服务器 = 小程序上不了线；国内用户延迟也差；
- **云数据库 RDS**：初期单机自托管 PG + 每日备份脚本足够，省 100+ 元/月，等日活过千或数据变关键再迁移。

## 三、阶段流程

### Phase 0 · 第 0 周：资质全启动（最重要的一个决定）

**主体类型是第一个、也是影响最大的决策**：

- ❌ **个人主体**：微信「深度合成-AI问答」类目**不对个人开放**（本产品的 AI 对话/AI 陪练属于此类）——个人主体的小程序无法带 AI 对话功能过审。
- ✅ **个体工商户**：成本低（免费登记，部分省份线上即办）、可微信认证、按非个人主体申请类目；**推荐 V1 用这个**。
- ✅ **公司**：如果计划收费/融资/多股东，直接注册小规模纳税人公司。

#### 主体注册实操：名下没有公司怎么办

三条路，推荐 A（个体工商户，最小代价拿到"非个人主体"身份）：

**A. 注册个体工商户（推荐，V1 够用）**
- **费用 0，多数省份线上 1-3 个工作日办结**：本省政务服务网/一网通办平台（如浙江「浙里办」、广东「粤商通」、上海「一网通办」），或线下到区级市场监督管理局；
- 需要：身份证 + 经营场所。多数地区支持**住所承诺制/住宅登记**；没有合适场所可用园区**集群注册/托管地址**（免费到几百元/年）；
- 字号建议带「网络科技/信息技术工作室」，经营范围含「技术开发、技术服务、软件开发、信息系统集成」等；
- 拿到营业执照后：微信小程序按**个体工商户主体**注册 → 微信认证（300 元/年）→ 申请类目；
- 税务：默认小规模纳税人，季度开票 ≤30 万免增值税（现行政策），没收入做零申报即可，负担很低；
- ⚠️ 唯一不确定点：深度合成类目资质审核对"企业主体"的口径——个体户属于非个人主体、可微信认证，大概率可行；**若提审被以主体类型驳回**，再走 B 方案，软著/域名/备案材料都可沿用，不白办。

**B. 注册有限公司（一步到位）**
- 自助注册 0-500 元，1-2 周；注册地址可用孵化器/园区集中办公地址（常免费到数百元/年）；
- 记账报税：可以自己零申报（要学基本流程），或代理记账约 2000-3000 元/年；
- 适合：确定要收费/接融资/多合伙人，或类目审核严格要求"企业"时。

**C. 完全不注册主体能走到哪一步？**
- H5：✅ 可以（个人 ICP 备案即可）；
- 小程序：可以注册个人主体，但**AI 对话功能过不了审**（深度合成类目不开放个人主体），等于砍掉产品核心；
- iOS：个人 Apple Developer + 个人 App 备案可以走通；Android：个人开发者账号部分商店可注册，软著著作权人也可以是个人，但 AI 类应用部分商店要求企业资质；
- 结论：**想做完整的 TalkBuddy（带 AI 对话），主体绕不开，个体户是最小代价路径**。

第 0 周动作清单：
1. 注册/确定主体 → 2. 买域名（如 `talkbuddy.cn` / `.com`，主体名与备案一致）→ 3. 提交 ICP 备案（阿里云备案控制台，填服务器信息需先开通服务器）→ 4. 注册微信小程序账号并发起微信认证 → 5. 提交软著申请（著作权人写主体名，**名称定为「英语搭子软件」或最终 App 名——软著名/APP备案名/应用名三者必须一致**，见 §四）→ 6. 注册 Apple Developer。

### Phase 1 · 第 1 周：服务器上线（技术活，1-2 天）

```bash
# 1. 阿里云控制台：轻量应用服务器 2C4G，选系统镜像 Ubuntu 22.04/24.04
#    防火墙只放行 22/80/443（轻量服务器默认只开 22/80/443，确认即可）

# 2. 服务器初始化
ssh root@<IP>
curl -fsSL https://get.docker.com | bash        # Docker + compose 插件

# 3. 部署代码
git clone <你的仓库> /opt/talkbuddy && cd /opt/talkbuddy
cp .env.example .env && vim .env                # 填全部[必填]项（密钥换新的，勿复用本地值）
./scripts/gen_certs.sh                          # 先用自签名，备案+解析后换 CA 证书
docker compose up -d --build

# 4. 域名解析：A 记录 talkbuddy.cn / www → 服务器 IP
# 5. ICP 备案通过后：申请免费 CA 证书（阿里云「数字证书管理服务」有 20 张/年免费 DV 证书）
#    下载 nginx 格式，替换 certs/fullchain.pem + privkey.pem，docker compose restart web
# 6. 把 compose 里 "8443:443" 改为 "443:443"（备案后正式启用）
```

验收：`https://你的域名/api/v1/health` 返回 `{"code":0,...}`；`http://` 自动跳 `https://`。
**同步做**：crontab 加每日数据库备份（README checklist 里有命令，保留最近 14 天并异地拷一份到 OSS）。

### Phase 2 · 第 2-3 周：H5 上线（备案通过后立即可用）

- ICP 备案通过 → 域名可直接访问 → H5 就是第一个上线渠道，可以先获客/验证。
- 网站底部放 ICP 备案号（如 `浙ICP备XXXXXX号`）并链接到 beian.miit.gov.cn（合规要求）。
- 用 `ADMIN_TOKEN` 跑一遍冒烟：`ADMIN_TOKEN=xxx bash scripts/smoke.sh`（本机或服务器上都行）。

### Phase 3 · 第 3-5 周：微信小程序上线（合规最重的一端）

1. **代码配置**：`app/src/manifest.json` 填真实 appid；`app/.env.production` 填 `VITE_API_BASE_URL=https://你的域名`；`npm run build:mp-weixin`。
2. **后台配置**（mp.weixin.qq.com）：
   - 开发管理 → 服务器域名：request 合法域名 + socket 合法域名填 `https://你的域名`（**域名必须已备案**）；
   - 用户隐私保护指引：声明收集的信息（昵称、麦克风——跟读/语音识别用到了录音权限，**必须声明**）；
   - 类目：基础类目按主体选择（见 §四）。
3. **深度合成-AI问答类目**（AI 对话功能必需）：
   - 你们走的是**第三方已备案大模型路径**（阿里云百炼/通义千问是已备案模型）；
   - 需要材料：阿里云（技术支持方）的《互联网信息服务算法备案》证明 + **双方合作协议**——通过百炼控制台/工单向阿里云索取，**协议里的模型名称必须与备案名称完全一致**（最常见的驳回原因）；
   - 备案证明彩色打印盖章后与协议一起上传。
4. **提审节奏**：开发版自测（开发者工具勾选「不校验合法域名」可用 localhost 调试）→ 传体验版给真人测试 → 提交审核（第一次审核常见 1-2 轮驳回，预留 1-2 周）→ 发布。
5. 审核注意：小程序内**不得出现诱导分享/虚拟支付直连**；教育向文案措辞见 §四。

### Phase 4 · 第 4-8 周：App 上线（iOS 与 Android 并行推进）

**打包**（HBuilderX 云打包，无需本地 Mac/证书知识）：
- Android：HBuilderX 生成/使用自有 keystore 签名 → 云打包出 APK；记录**包名**（如 `cn.talkbuddy.app`）与证书指纹；
- iOS：需要 Apple Developer 证书（.p12 + 描述文件）→ 云打包出 ipa。

**App 备案**（在已通过的 ICP 备案系统里追加 App 信息，阿里云控制台操作）：
- 填 App 特征信息：Android 包名 + 证书 MD5/公钥；iOS 的 Bundle ID + 公钥；
- 填的**App 名称必须与软著名/商店上架名一致**；
- 管局审核 3~22 个工作日——**这是 App 上架的前置，拿到备案号才能在商店过审**。

**iOS（App Store）**：
1. App Store Connect 创建 App（名称=备案名）→ 填**中国区 ICP 备案号**（强制，自动校验一致性）；
2. 上传 ipa（Transporter 或 altool）→ TestFlight 内测 → 提审；
3. 审核关注点：AI 生成内容需有举报/屏蔽机制（应用内加个「举报」入口即可满足基本要求）；隐私清单（PrivacyInfo.xcprivacy）声明收集项；订阅/内购如走苹果支付需接 IAP——**V1 若免费则无此问题**。

**Android（各商店）**：华为 / 小米 / OPPO / vivo / 应用宝，逐家注册开发者账号（企业主体 + 对公验证或保证金）→ 提交 APK + 软著 + App 备案号 + 隐私政策链接 → 各家 1-3 天审核。**软著 + 备案号是所有商店的硬门槛**。第一批先上华为 + 小米 + 应用宝覆盖大半安卓用户即可，其余后续补。

### Phase 5 · 上线后运维（持续）

| 事项 | 做法 | 频率 |
| --- | --- | --- |
| 数据库备份 | cron `pg_dump` + 拷贝 OSS | 每日，保留 14 天 |
| 证书续期 | 阿里云免费 DV 证书一年期，到期前 30 天换发 | 每年 |
| 日志 | 已按天轮转落盘（`docker compose logs` + lingo-logs 卷），异常 grep ERROR | 每周巡检 |

| 监控告警 | 阿里云轻量自带监控（CPU/磁盘）+ 云监控对 `/api/v1/health` 做拨测告警 | 一次性配置 |
| 系统补丁 | `apt update && apt upgrade` + `docker compose pull` | 每月 |

## 四、合规与风险（必读）

### ⚠️ 1. 教育类目红线：英语 = 学科类培训

「双减」后**少儿英语按学科类培训管理**（[教育部：线上学科类培训机构由备案改为审批制](http://www.moe.gov.cn/srcsite/A29/202109/t20210918_564368.html)，需要《民办学校办学许可证》+ 全国校外教育培训监管与服务综合平台备案——个人/小团队办不下来）。本产品含小学/初中/高中派课方向，**不能以「在线教育/培训机构」类目和口径上线**（[微信小程序服务类目及资质要求](https://developers.weixin.qq.com/minigame/product/material/)，其中教育服务类目明确要求办学许可等资质；英语点读/工具类产品是否需要资质可参考[微信社区官方答复](https://developers.weixin.qq.com/community/develop/doc/0008e4755ccc60a5b374036726fc00)）。

**务实路径：定位为「AI 学习工具」**：
- 类目避开「教育服务-在线教育」，选工具类/教育信息服务（以[提审时类目要求](https://developers.weixin.qq.com/minigame/product/material/)为准）；
- 全端文案**不出现**「培训」「授课」「班课」「名师教学」「课程售卖」等表述——用「AI 陪练」「口语练习工具」「学习搭子」；
- 不内置付费购课（付费会触发更严的资质与资金审查）；捐赠式/会员制也先观望；
- 面向成人的职场/出境口语方向风险低；少儿方向（ageBand=少儿）在小程序提审时是敏感点，**V1 可先在服务端把少儿档下架**（`GUEST_ENABLED` 同级的配置开关思路），或文案明确「工具自用，非培训服务」；
- iOS 审核对教育工具类相对宽松，但同样适用上述措辞原则。

### ⚠️ 2. AI 对话 = 深度合成类目（小程序）

- 个人主体**办不了**（§三 Phase 0 的结论）；
- 用已备案第三方大模型（百炼/通义）+ 合作协议是标准路径，材料要求见[腾讯云算法备案资质说明](https://docs.cloudbase.net/ai/release/algorithm-filing)（微信通用规则：协议中的模型名称必须与备案名称完全一致）；
- 对话内容需有基本的安全机制：当前依赖 DashScope 自带的内容安全护栏即可满足大部分审核；建议 V2 加用户举报入口与关键词日志。

### ⚠️ 3. 名称一致性（防返工）

**软著名 = App 备案名 = iOS/安卓上架名 = 小程序名称**（允许微小后缀差异，但主体词一致最稳）。定名后所有材料统一用「英语搭子」（示例），避免中途改名——改一次名，软著/备案跟着折腾一轮。

### ⚠️ 4. 隐私合规（全端）

- 小程序：用户隐私保护指引（昵称、**录音权限**——跟读评分与语音识别用到）；
- App：隐私政策 URL（放 H5 域名下，如 `/privacy.html`）+ 各商店隐私声明；收集手机号的话（`t_user.phone`）必须明示用途并支持删除；
- iOS：PrivacyInfo.xcprivacy 清单 + App Tracking 透明度（本项目不追踪，填「否」）。

## 五、一页 Checklist（按顺序打勾）

```
[ ] 主体：个体工商户/公司注册完成
```
